简体中文支持

仅打开您有权访问的文件 本应用只提供 DCM/DICOM 文件导入、显示、元数据查看和本地整理功能，不分析文件内容或给出结论。

导入文件

  1. 打开“资料库”，点按右上角“导入”。
  2. 选择“导入文件”或“导入文件夹”。
  3. 在系统“文件”界面中选择 DCM/DICOM 内容。
  4. 等待扫描与本地保存完成，再打开序列。

查看文件

  • 浏览：上下拖动或使用序列滑块。
  • 窗位：拖动调节窗宽与窗位，或使用预设。
  • 平移与缩放：选择工具后拖动，也可双指缩放。
  • 工具栏还提供播放、旋转、反色和重置。
  • 点按信息按钮查看 DICOM 元数据。

兼容性

应用面向常见的未压缩 DICOM 文件及若干常用压缩传输语法。部分视频、流式内容、专用传输语法或复杂增强型多帧对象可能无法完整显示。遇到不支持的内容时，应用会显示明确错误。

常见问题

选择文件后没有出现内容
确认文件是有效 DICOM，而不是仅更改了扩展名。尝试导入完整文件夹，并等待云端文件先下载完成。

画面全黑、全白或对比度不合适
尝试“通用预设 A”至“通用预设 D”，也可以使用窗位工具手动调节。某些文件包含特殊显示参数，当前版本可能不支持。

切片顺序不正确
应用优先使用 DICOM 几何位置排序，并在缺少相关标签时回退到实例编号。若源文件缺少或写入了错误标签，请向文件提供方获取完整、正确导出的序列。

导入失败或设备存储不足
在系统“设置”中检查可用存储空间。大文件、文件数量过多、损坏文件或不支持的像素格式可能被安全拒绝。

隐私与删除

导入后的文件保存在应用的本地受保护空间，不上传给开发者或第三方。您可以左滑删除单个序列，或在“设置”中删除全部内容。详情请阅读隐私政策。

English support

The current app interface is Simplified Chinese. The steps below show the visible Chinese label beside its English meaning.

Open only files you are authorized to access This app provides DCM/DICOM file import, display, metadata inspection, and local organization. It does not analyze file content or provide conclusions.

Import files

  1. Open Library (资料库) and tap Import (导入) in the top-right corner.
  2. Choose Import File (导入文件) or Import Folder (导入文件夹).
  3. Select DCM/DICOM content in the system Files interface.
  4. Wait for scanning and local storage to finish, then open the series.

View files

  • Browse: drag vertically or use the series slider.
  • Window/level: drag with the window tool or choose a preset.
  • Pan and zoom: select a tool and drag; pinch to zoom also works.
  • The toolbar also provides playback, rotation, inversion, and reset.
  • Tap the information button to inspect DICOM metadata.

Compatibility

The app is designed for common uncompressed DICOM files and several widely used compressed transfer syntaxes. Some video, streamed content, specialized transfer syntaxes, or complex enhanced multi-frame objects may not display completely. Unsupported content produces a clear error.

Troubleshooting

No content appears after selecting a file
Confirm that it is a valid DICOM file, not only a renamed extension. Try importing the complete folder, and allow a cloud-hosted file to finish downloading first.

The display is black, white, or has poor contrast
Try General Preset A through General Preset D, or adjust window and level manually. Some files contain specialized display parameters that this version may not support.

Slices appear out of order
The app prefers DICOM geometry for sorting and falls back to instance number when geometry tags are missing. Ask the file provider for a complete, correctly exported series if the source contains missing or incorrect tags.

Import fails or storage is low
Check available storage in system Settings. Very large imports, too many files, damaged files, or unsupported pixel formats may be rejected for safety.

Privacy and deletion

Imported files remain in protected local app storage and are not uploaded to the developer or third parties. Swipe to delete a series or delete all content in Settings. Read the Privacy Policy for details.
